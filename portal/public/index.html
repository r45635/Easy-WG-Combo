Niveaux de protection DNS

        
      

      

        

          
Filtré complet

          
Bloque les publicités, les trackers, les malwares et le phishing.

          
Via AdGuard Home sur le VPS — listes AdGuard DNS filter, AdAway et Malware filter. Les pages se chargent plus vite, moins d'exposition aux contenus indésirables.

          
Recommandé pour : tous les appareils du quotidien.

        

        

          
Malware seulement

          
Bloque les malwares et le phishing. Les publicités et trackers passent.

          
Via Cloudflare for Families (1.1.1.2) comme DNS upstream. Les pubs restent visibles.

          
Recommandé pour : appareils où un bloqueur de pub est déjà installé (uBlock, etc.).

        

        

          
Sans filtre

          
Aucun blocage — résolution DNS directe via Cloudflare (1.1.1.1).

          
Compatibilité maximale. Utile pour le débogage ou accéder à des ressources normalement filtrées.

          
Recommandé pour : développeurs, tests, cas spécifiques.

        

        

          Note : Seuls les clients dont la config utilise DNS = 10.8.0.1
          peuvent changer de filtre à la volée. Les autres nécessitent une nouvelle configuration.
